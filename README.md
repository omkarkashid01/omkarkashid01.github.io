# Omkar Kashid — Personal Profile

A responsive personal profile/portfolio website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main page
- `style.css` — responsive styling and animations
- `script.js` — menu, scroll reveal and subtle mouse effect
- `assets/profile.jpg` — profile image
- `Seminar-2.pdf` — academic seminar PDF, linked and embedded in the Seminar section

## GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` (or enable Pages in any repository).
2. Upload all files while keeping the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from branch → choose `main` and `/root`.
4. Open your GitHub Pages URL.

The Instagram button points to `@omkar_kashid_05`.
